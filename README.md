проект по Page Object Mode Яндекс.Практикум (Автоматизация тестирования)

Структура 

в файлах директории locators определены локаторы, используемые в тестах
в директории page_object содержатся файлы с классами для каждой тестируемой страницы
в директории tests лежат файлы с тестами

файл conftest содержит фикстуры, необходимые для запуска тестов
файл data хранит тестовые данные полей ввода

директория allure_results содержит JSON-файлы с результатами выполнения тестов для генерации отчета
в файле requirements.txt перечислены все внешние зависимости исполняемых тестов для удобной установки одной командой

Тесты

тесты в файле test_main_page проверяют соответствие текста ответов в разделе «Вопросы о важном» на главной странице приложения
тесты в файле test_order покрывают весь флоу позитивного сценария оформления заказа. Используются два набора пользовательских данных, передаются через параметризацию. Для входа в сценарий использованы две разные точки входа.
тесты в файле test_scooter_yandex_logo проверяют переходы на главную страницу сервиса и на главную страницу «Дзена»
